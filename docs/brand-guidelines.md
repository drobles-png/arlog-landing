# Arlog — Guía de marca (landing)

Fuente: logo oficial "ARLOGS · IMPROVING LOGISTICS" (`brand/logo-original.png`).

## Colores
| Token | Hex | Uso |
|---|---|---|
| Navy 900 | `#040A26` | Fondo base (el mismo del logo) |
| Navy 800 | `#08113A` | Secciones alternas, modales |
| Navy 700 | `#0E1A52` | Tarjetas |
| Navy 600 | `#1A2A6E` | Bordes y divisores |
| Azul (aéreo) | `#2C55A4` | Acento, paso 1 |
| Azul claro | `#6F9BE6` | Eyebrows, iconos, enlaces sobre navy |
| Índigo (marítimo) | `#2A2A8C` / `#3D3DB3` | Acento, paso 2 |
| Naranja (terrestre) | `#D16304` | Acción: botones, barra superior, paso 3 |
| Naranja suave | `#FFB26B` | Cifras y énfasis de texto sobre navy |
| Texto | `#EEF2FF` / `#A9B4D8` / `#7884B0` | Principal / secundario / terciario |

Regla: el naranja es solo para acción y para el número que importa. Los tres paneles del logo
(azul, índigo, naranja) se usan como motivo en franjas inclinadas y en los 3 pasos de la clase.

## Tipografía
- **Lato 900** — titulares (misma familia del wordmark).
- **Source Sans 3** — cuerpo (400/600).
- **IBM Plex Mono 500** — cifras y costos.

## Voz
Primera persona de Ángel, directa, de "tú", sin promesas infladas. Solo se usan los datos y frases
del VSL.
